# Documentation Index

This index centralizes all project documentation and provides direct links.

## Core Documents

- [Project Recap](./PROJECT-RECAP.md): project goals, constraints, tasks, and acceptance criteria.
- [Main README](../README.md): repository overview, quick start, and main navigation.

## Reporting

- [Report Template](./report/REPORT-TEMPLATE.md): template for periodic progress and habit tracking reports.
- `report/`: folder containing dated reports generated from the template.

## Change Tracking

- [Variable Registry](./changes/VARIABLE_REGISRTY.md): tracked variables and hyperparameters, rationale, and observed impact.
- [Experiment Changelog](./changes/CHANGELOG-EXPERIMENTS.md): chronological log of experimental changes, hypotheses, and outcomes.

## Variable Explanations

- [Variable Explanations](./changes/VARIABLES-EXPLAINED.md): readable explanations of key variables used in training and evaluation.

## How to Use This Documentation

1. Start with [Project Recap](./PROJECT-RECAP.md).
2. Use [Report Template](./report/REPORT-TEMPLATE.md) for each reporting period.
3. Update [Variable Registry](./changes/VARIABLE_REGISRTY.md) whenever a variable is introduced or modified.
4. Add an entry to [Experiment Changelog](./changes/CHANGELOG-EXPERIMENTS.md) for each meaningful experiment change.
5. Keep [Main README](../README.md) and this index aligned as structure evolves.
